> 适用版本 **v0.2.1** ｜ 整理日期 2026-10-18 ｜ 平台 Windows 10/11 x64

本文是"给四季各设计一套衣服，并且好做成 Live2D 嵌进桌宠"的完整方案，只讲设计与实现路径，不含成品美术。配套阅读：

- `psd/图层说明.md` —— 现有 82 层的分组、来源与已知问题
- `docs/小嬅_Live2D拆件与绑定方案.md` —— 变形器、参数、物理、动作的原始规划
- `tools/build_wardrobe.js`、`assets/app-dress.js` —— 现有换装的打包与运行时

## 0. 一句话结论

**四季不做四套新模型，做成"同一骨架上的四套衣装皮肤"**：共用现有 82 层、共用变形器、共用物理与参数，只换「布料贴图 + 2–3 个覆盖件 + 兜帽开关」。这样 Live2D 那边不用重建工程，桌宠这边也不用改渲染，换季就是换图。

---

## 1. 四条硬约束

这四条是照着现有分层实测出来的，直接决定哪些设计能做、哪些不能做：

| # | 约束 | 依据 | 对设计的影响 |
|---|---|---|---|
| 1 | **斗篷一隐藏，躯干是空的** | `Sweater` 层只覆盖 y 1058–1343，肩胸处没有完整身体（`图层说明.md` 里"躯干被遮部分"本就是【补画】项） | 「夏天脱斗篷」不能只靠隐藏层，必须补画躯干或用覆盖件盖住 |
| 2 | **袖子长在 `Sweater` + `Hand_R/L` 上**，且手是连在袖口里画的 | 分层时"毛衣"是一整层，"右手（袖）"含袖口与拳头 | 无袖 / 短袖 = 重画整条手臂，是全套方案里最贵的一项 |
| 3 | **`Cape_Hem_R/L` 隐藏后是生硬的直线切口** | 下摆只在 y>1401 单独成层，切口没有收边 | 短斗篷必须配下摆边饰或重画下摆，不能靠隐藏 |
| 4 | 现有参数已覆盖全部衣服动作 | `ParamCapeHem` / `ParamSkirt` / `ParamBreath` / `ParamCapeGrip` / `ParamHoodRim` / `ParamScarfSway` / `ParamBagSway` | 新件全部挂现有变形器，**不新增参数**，动作与物理文件零改动 |

另外两个已经验证过的好消息：

- **贴图混色成立**：把格纹贴到斗篷上，原画的明暗和体积感都还在（渲染器按原图亮度调制图案），所以"换布"能做出真实衣物质感，而不像贴色块。
- **摘兜帽效果很理想**：兜帽下的头发、麻花辫是完整画过的，隐藏 `Hood_*` 直接得到一个新剪影，零成本。

## 2. 设计原则（Live2D 友好的五条）

1. **同 UV、同尺寸**：所有换装贴图按原坐标出图（PSD 3040×5404 / 网页 1200×2133），换布时 ArtMesh 与 UV 完全不动，只重导贴图。
2. **覆盖件只挂现有变形器**：头饰 → `Warp_Head_XY`；下摆边饰 → `Warp_CapeHem_L/R`；兜帽毛边 → `Warp_Hood_Rim`；毛领/围巾 → `Warp_Torso` + 现有围巾物理。绝不新建平行骨架。
3. **一季只给一个主色、一个剪影开关、一个标志道具**。桌宠窗口只有 300px 宽，元素一多就糊。
4. **不做真半透明**：薄纱靠颜色、边线、褶皱做"轻"，不要用 alpha<1，避免 Cubism 与 WebGL 的图层排序问题。
5. **新件都是独立 ArtMesh**，不合并进原层，方便以后单件加/删而不动已绑好的部分。

## 5. Live2D 怎么嵌

### 5.1 三条路线

| 路线 | 做法 | 适用 | 代价 |
|---|---|---|---|
| **A 纹理换装** | ArtMesh 与 UV 完全不动，只换贴图集（同尺寸、同 UV 布局） | 斗篷 / 毛衣 / 裙子这类"剪影不变只换布"的层 | 最省，一个模型跑四季 |
| **B 覆盖件** | 单模型内加 ArtMesh，挂在现有变形器下，用 Part 不透明度或开关切换 | 花冠、草帽、蕾丝 / 流苏 / 毛边、毛领 | 每件 1 个 ArtMesh + 1 个父变形器 |
| **C 多模型皮肤** | 同一 PSD 结构导出 4 个 `model3.json`，共用动作与物理文件 | 以后真做剪裁（无袖、大衣）时 | 每季多一套贴图 + 多一次导出 |

**推荐组合：A + B。** 四季先做成"一个模型、一套动作、一套物理"，只有三期真剪裁的那几件才走 C。这样桌宠、网页看板娘、宣传录屏可以共用同一个 `moc3`。

### 5.2 Cubism 端要点

- 所有衣装 ArtMesh 都放在现有 `Warp_Body_Z → Warp_Body_XY → Warp_Breath` 链下，**不要新建平行骨架**，否则动作文件要重做。
- 覆盖件父子关系：
  - 头饰 → `Warp_Head_XY`（跟头转、跟歪头）
  - 下摆边饰 → `Warp_CapeHem_L/R`（跟斗篷物理甩）
  - 兜帽毛边 → `Warp_Hood_Rim`（跟帽沿轻晃）
  - 毛领 / 围巾 → `Warp_Torso` + 现有围巾物理组
- 切换方式：用 Part 不透明度 0/1 最稳；如果要"换装有过渡"，再加一个 0–3 的 `ParamOutfit` 做淡入淡出，别用参数直接驱动顶点。
- 贴图：每季 2048² 一张，共用同一套 UV；换季只重导贴图，不动网格。
- 导出两套纹理（2048 给桌宠/网页、4096 给录屏），模型数据共用。

### 5.3 桌宠 / 网页端要点

现有渲染器（`assets/app-render.js`）已经支持逐层 tint、图案混合、`hide` 隐藏，四季**不需要改 WebGL**。要动的只有三处：

1. `tools/build_wardrobe.js`：套装定义里增加 `hide`（该季隐藏哪些层）与 `extras`（该季启用哪些覆盖件），并把新件打进图集。
2. `assets/app-dress.js`：`hideMap()` 合并套装隐藏集；`surface()` 返回该季贴图/图案；自动切换从"按小时"改成"按月份"（3–5 春 / 6–8 夏 / 9–11 秋 / 12–2 冬）。
3. `desktop-pet/web/panel.html` 与 `pet.js`：换装页从 5 套换成 4 季 + 原版，`DEF` 与 `sv` 升一版。

图集容量注意：现有 3 页 2048² 已接近满，四季 6 件边饰 + 2 件头饰建议单独开一页。

## 7. 生产流程

### 7.1 用 AI 生成（现管线）

现有 `psd/raw/wardrobe/` 里的配饰就是 Seedream 生成的：白底、单独一件、正视图。四季覆盖件可以照同样的路子出：

| 季节 | 提示词关键词（可直接喂给即梦 / Seedream） |
|---|---|
| 春 | 樱花，浅粉，薄纱，蕾丝花边，花冠，奶油色描线，扁平插画，单一物体，白底，无阴影 |
| 夏 | 麦秆草帽，宽檐，蓝色缎带，亚麻质感，荷叶边，柔和日光，扁平插画，白底 |
| 秋 | 焦糖格纹，毛线流苏，桦叶金黄，厚针织，羊毛质感，暖秋色调，扁平插画，白底 |
| 冬 | 奶油色毛边，蓬松毛领，雪花暗纹，霜蓝阴影，厚羊毛，扁平插画，白底 |

生成后按第 6 节尺寸框缩放、抠图、放到对应坐标，再跑一次打包脚本即可。

### 7.2 用画师

交付 PSD：一个"覆盖件"一个图层组，命名 `中文名 | EnglishName`，与现有层同画布同坐标；另附一张 UV 对照说明（哪些层换了贴图）。

### 7.3 建模

1. 导入 PSD，保持现有层级不变；
2. 覆盖件建 ArtMesh，挂到 5.2 指定的父变形器；
3. 只用现有参数打关键帧，不新增参数；
4. 四个套装用 Part 不透明度或 `ParamOutfit` 切换；
5. 导出 2048 / 4096 两套纹理。

## 8. 三期落地与工时

| 期 | 内容 | 工时 | 能看到的差别 |
|---|---|---|---|
| **一期** | 只做"材质换季"：4 套贴图 + 兜帽开关 + 现有配饰组合 | 1–2 天 | 颜色与质感四季分明，剪影只有兜帽变化 |
| **二期** | 补齐 8 件覆盖件（下摆 ×4、边饰 ×4、头饰 ×2） | 画 1–2 天/季，绑 0.5 天/季 | 剪影换季成立，是性价比最高的一期 |
| **三期** | 真剪裁：夏无袖、冬大衣、春连衣裙 | 每季 +1 天画 +1 天绑（需补画躯干与手臂） | 完全换装，但成本翻倍 |

**建议顺序：秋 → 冬 → 春 → 夏。**
秋最省、冬效果最强、春靠花冠就能立住、夏必须重画下摆和袖子，放最后。

## 9. 验收清单

每季过一遍：

- [ ] 300px 窗口下，不放大也能一眼认出是哪个季节
- [ ] 兜帽开 / 关切换时，头发、辫子、斗篷接缝不露底
- [ ] 转头 ±30°、歪头 ±30°，新件不穿模、不脱离
- [ ] 拖拽摇晃时，边饰跟着斗篷甩、头饰跟着头甩，不会"钉"在原地
- [ ] 眨眼、说话、呼吸时，衣装不闪、不裂
- [ ] 换季切换是瞬切还是淡入，没有中间态残留
- [ ] 新贴图与旧贴图 UV 对齐，换装后没有整体位移
- [ ] 点击穿透判定没有被新件撑大（透明区域仍可穿透）

## 10. 风险与已踩的坑

1. **躯干空洞**：任何"脱斗篷"的设计都要先补画躯干，否则会露馅。建议把"完整躯干"作为共用底图，一次画好四季复用。
2. **袖子**：无袖是唯一真正贵的地方，一期二期都不要碰。
3. **下摆切边**：短摆必须重画，不能靠隐藏（已实测，隐藏后是硬直的切口 + 背后内衬悬空）。
4. **图集容量**：现有 3 页 2048² 已接近满，四季覆盖件建议单独一页。
5. **半透明薄纱**：Cubism 与 WebGL 的透明层排序都容易出问题，春/夏的"薄"靠颜色和边线做，不要真做 alpha。
6. **中文编码**：所有新文件保持 UTF-8 无 BOM，与现有源码一致。
