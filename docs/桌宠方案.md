# 小嬅桌宠方案

目标：把现在的网页预览（`index.html` + `assets/`）变成常驻桌面的桌宠。窗口透明、可拖动、可互动，平时安静不打扰。

## 1. 技术路线

| 方案 | 安装包 / 内存 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| **Tauri 2**（系统 WebView2 + Rust） | 约 8–12 MB / 80–150 MB | 体积小；现有网页代码可直接使用；支持透明窗口、托盘、开机自启、自动更新 | 点击穿透要写少量 Rust；需要 Rust 工具链 | **推荐** |
| Electron | 约 80–120 MB / 150–250 MB | 生态成熟；`setIgnoreMouseEvents(true, {forward:true})` 一行就能实现点击穿透；纯 JS | 体积大、内存高 | 备选（适合想纯 JS 快速出原型） |
| Live2D Cubism SDK + Unity | 50 MB 以上 | 官方格式，动作和物理的编辑器更完整 | 要在 Cubism Editor 里重新绑定骨骼，工作量大 | 以后想上架或商用时再考虑 |
| 原生 C++/C#（如 WPF 窗口 + WebView2） | 小 | 能精细控制系统行为 | 开发慢 | 不推荐 |

现在的渲染器是纯 WebGL 1，不依赖任何框架，三种 WebView 宿主都能直接运行。

## 2. 窗口与交互

- **透明窗口**：无边框、透明背景、不显示在任务栏、始终置顶（可在托盘关闭）。页面背景设为 `transparent`，去掉面板和按钮，只保留舞台。
- **点击穿透**：只有点到角色本身才响应，点到空白处会穿透到下面的软件。
  - 每帧（或每 50ms）读取鼠标位置下 WebGL 画面的透明度（`gl.readPixels` 读 1 个像素）。不透明就关闭穿透；透明就开启穿透。
  - Tauri：`window.set_ignore_cursor_events(bool)`，用全局鼠标轮询（`device_query` crate）判断鼠标位置。
  - Electron：`win.setIgnoreMouseEvents(true, { forward: true })` 后照常收到 mousemove，直接用现有逻辑即可。
- **拖动**：按住角色拖动的是整个窗口（Tauri `startDragging()` / Electron 手动 `setPosition`）。拖动时复用现有的拖拽倾斜和落地（`drop`）动作。
- **贴边**：松手时如果离屏幕边缘不到 40px 就吸附过去，并只探出半个身子。鼠标靠近时她会探出来看你，再点一下就整个出来。
- **大小**：50%–150% 共 5 档，可用托盘菜单或 Ctrl+滚轮调整。窗口尺寸按比例缩放，渲染器的 `resize()` 已经支持。
- **多显示器与记忆**：记住上次所在的显示器、位置和大小（用 `tauri-plugin-store` 存成 JSON）。显示器被拔掉时回到主屏右下角。
- **托盘菜单**：显示/隐藏、大小、置顶、勿扰模式、提醒设置、开机启动、关于、退出。

## 3. 行为设计（状态机）

```
             长时间无操作 5 分钟                 再过 10 分钟
  [活跃] ─────────────────────▶ [犯困: 打哈欠] ──────────────▶ [睡觉 zzz]
    ▲  ▲                                                          │
    │  └──── 点击 / 拖动 / 鼠标靠近 ◀──────────────────────────────┘ (wake)
    │
    ├─ 每 6–15 秒：待机小动作（眨两下 / 东张西望 / 歪头 / 晃身体 / 深呼吸）← 已实现
    ├─ 鼠标靠近 300px 以内：眼 → 头 → 身体依次看向鼠标 ← 已实现
    ├─ 你正在打字（全局键盘活动）：安静模式，只做呼吸和眨眼，不说话
    └─ 前台是全屏程序（游戏 / 视频 / 演示）：自动隐藏，退出全屏后再出现
```

- **点击反应**：沿用网页版，包括摸头、点身体（随机害羞或歪头）、点云朵、连点 3 次生气。
- **定时提醒**（可开关）：
  - 喝水：每 60 分钟，她举着小云朵提醒你；
  - 久坐：每 50 分钟，伸懒腰（复用 `yawn`）并显示气泡“起来走走吧”；
  - 整点报时：点头加气泡；
  - 番茄钟：25 + 5 分钟，开始时 `greet`，结束时 `hop`。
- **时间段**：早上第一次打开时打招呼；23 点以后会提醒睡觉，打哈欠的频率也变高。

## 4. 可选功能（分期）

1. **气泡对话**：在角色头顶画一个圆角气泡（复用现有的 `toast`，改成跟随头部位置）。台词库用 JSON 维护，按状态和时间段分类，每类准备 5–10 句。
2. **语音和口型**：每句台词配一段预录音频（或用 TTS 生成），用 Web Audio 读取音量来驱动 `ParamMouthOpenY`，实现口型同步。
3. **AI 聊天**（扩展）：在托盘中打开输入框，接入大模型 API，按回复的情绪播放对应动作（开心 → hop，疑问 → tilt，生气 → angry）。需要提示用户注意隐私和费用。
4. **换装**：现在的 PSD 已分好层，可以给毛衣、斗篷、发饰另画几套，按图层 id 替换图集。

## 5. 性能目标

| 场景 | 帧率 | CPU 目标 |
|---|---|---|
| 正在互动 / 鼠标在附近 | 60 fps | < 5% |
| 待机 | 30 fps | < 2% |
| 睡觉 / 窗口被完全遮挡 | 10 fps / 暂停 | ≈ 0% |

- 渲染区域：只渲染角色周围的窗口区域（约 360×640）。图集可以从 3 张 2048² 缩成 2 张 1024²（桌宠显示尺寸小，清晰度足够），显存从约 48MB 降到约 8MB。
- 网格：桌宠尺寸下网格密度可以从 24px 一格放宽到 40px 一格，顶点计算量约减少 60%。
- 常驻内存目标在 150MB 以内（Tauri）。

## 6. 分期与工作量

| 期 | 内容 | 预计 |
|---|---|---|
| 一期 MVP | Tauri 工程；透明置顶窗口；去掉面板；点击穿透；拖动和吸附；托盘里的显示/隐藏和退出；记住位置 | 1–2 天 |
| 二期 | 大小档位；开机自启；勿扰和全屏自动隐藏；睡觉/唤醒状态机；喝水、久坐提醒和番茄钟；Windows 安装包（NSIS / MSI） | 2–3 天 |
| 三期 | 气泡台词库；语音和口型；自动更新；macOS 版本（透明窗口要单独适配） | 3–5 天 |
| 扩展 | AI 聊天；换装；多角色 | 另行评估 |

### 一期目录结构建议

```
xiaohua-pet/
  src-tauri/            Rust：窗口、托盘、点击穿透、全局鼠标轮询、自启
    tauri.conf.json     transparent: true, decorations: false, alwaysOnTop: true, skipTaskbar: true
  web/
    pet.html            从 index.html 精简：只保留 <canvas id="gl"> + <canvas id="fx">
    assets/             直接复用 app-core.js / app-render.js / app.js / xiaohua_layers.js
    pet-bridge.js       与宿主通信：拖动窗口、穿透开关、提醒触发、设置读写
```

`app.js` 需要的改动：
- 把面板、按钮相关代码改成可选；
- 暴露 `XH.debug.play` 给宿主调用（已有）；
- 增加 `hitAlpha(x, y)`，用于判断点击穿透。

## 7. 将来转 Live2D Cubism 官方格式

- `psd/xiaohua_layers.psd` 的图层命名和分组已经按 Cubism 的习惯整理好（英文 id、左右后缀、被遮挡部分已补全），可以直接导入 Cubism Editor。
- 参数名和 Cubism 标准参数一致（`ParamAngleX/Y/Z`、`ParamEyeLOpen`、`ParamBodyAngleX`、`ParamBreath`……）。在 Editor 里按 `图层说明.md` 中的变形说明重新绑定变形器后，动作可以按关键帧手动迁移成 `.motion3.json`。
- 迁移以后，桌宠的宿主可以换成 Cubism Web SDK，窗口和交互部分仍然可以沿用本方案。
