## 1. 调研结论（重庆大学公开网站）

本机直连实测（2026-10-19）：

| 来源 | 地址 | 结论 |
|---|---|---|
| 新闻网 7 个栏目 | `news.cqu.edu.cn/{zhxw,jxky,zsjy,xysh,mtzd,tzggjb,xsjzyg}.htm` | ✅ 博达 CMS，列表项 `div.rdate[date=YYYY-MM-DD]` + `div.title a`，正文 `.v_news_content` |
| 学校主页通知公告 | `www.cqu.edu.cn/tzgg.htm` | ✅ 列表带日期 |
| 研究生院 | `yz.cqu.edu.cn` | ✅ `news/YYYY-MM/NNNN.html` |
| 教务处 | `jwc.cqu.edu.cn` | ❌ 返回 412 反爬挑战；**不绕过** |
| 图书馆 | `lib.cqu.edu.cn` | ❌ 前端渲染空壳 |
| 学生处 | `xsc.cqu.edu.cn` | ❌ 域名解析不到 |
| 微信公众号 | — | ❌ 无公开接口，搜狗微信有验证码；**改用你自己配置的 RSS** |

两个网站都没有 robots.txt。礼貌策略：每天最多刷新 2 次、每次每个栏目 1 个请求、请求间隔 ≥1 秒、只取列表和被选中报道的那 1 篇正文。

**网络注意**：你本机走 `127.0.0.1:2080` 代理时重大网站连不上（TLS 握手失败），直连正常。Rust 的 ureq 默认不走系统代理，所以桌宠里直接可用；RSS 若需要走代理再加开关。

## 2. 分五期

### A · 表情跟着话走 + 说话有记忆

- **多情绪标签**：提示词允许在情绪转折处插标签（每句最多 3 个，例如“[开心]好呀！[害羞]不过……”）；`chat.js` 记录每个标签在正文里的位置，气泡（`app-bubble.js`）新增 `mark(fn)`，打字机打到那个位置才切表情；侧边窗的情绪小图标也跟着换。
- **每日小结**：`memory.js` 新增 `diary`：每天第一次空闲时，把前一天的对话总结成 1–2 句（后台请求，失败静默），保留 60 天；提示词注入最近 3 天的小结 + 与当前话题相关的更早小结。
- **事件回访**：记忆里带日期的事件（面试、考试、出去玩）到了日期之后，挑合适时机主动问一句结果；问过就标记，不重复。
- **自然提起往事**：提示词鼓励在相关时自然带一句（“之前你说喜欢下雨天”），并限制频率，不逐条复述。

### B · DDL

- 面板新增「校园」页（第 6 个标签），上半部分是 DDL：列表按截止时间排序、倒计时（今天 / 明天 / 还剩 N 天）、颜色分紧急程度；新增 / 编辑表单（标题、日期 + 时间、课程 / 分类、备注、重要程度、提醒提前量多选），完成打勾、删除、显示已完成。
- 存 `localStorage['xh-ddl']`。
- 提醒：每 30 秒检查；到「提前量」时她用对话气泡提醒并写进记录（同一提醒只说一次）；每天第一次开机或早上 8 点后第一次用电脑，汇总“今天 / 明天有哪些 DDL”；过期标红。免打扰时段内只提醒 1 小时以内的。
- 聊天工具：`add_ddl` / `list_ddl` / `finish_ddl`（“下周三晚上十点交高数作业”）。

### C · 每日运势

- 本地按「日期 + 你的称呼」生成：总运势和学业 / 人际 / 财运 / 健康星级、幸运色、幸运数字、宜 / 忌（学生向词库，例如“宜：去图书馆、早点交作业；忌：熬夜、拖 DDL”）、一句今日小语。同一天结果固定。
- 入口：面板「互动」页「今日运势」按钮、聊天里问「今天运势怎么样」（工具 `get_fortune`）、早上主动搭话时偶尔提一句。
- 开了对话时由模型用小嬅的语气讲，没开时用模板气泡；标注“仅供娱乐”。

### D · 学校信息 + RSS + 每日校园新闻

- 设置：学校（目前只有「重庆大学」）、身份（本科生 / 研究生 / 考研·报考 / 老师·其他，决定各栏目权重）、每日播报开关、各来源开关、RSS 地址列表。
- Rust 新 `campus.rs`：`campus_fetch{url}` 直连抓取，只允许 `*.cqu.edu.cn` 和你在面板里加过的 RSS 地址（Rust 侧单独存一份白名单），10 秒超时、限 2MB；网页端用 `DOMParser` 解析列表 / 正文 / RSS。
- 缓存 `xh-campus`：每个来源最近 30 条（标题、链接、日期、来源），每天刷新 ≤2 次。
- 每日报道：10:00–21:00 随机时刻、你在用电脑且不在会议 / 游戏 / 全屏时，按身份权重挑一条近 3 天没播过的，抓正文让模型概括成一两句（没开对话就念标题），气泡里说，侧边窗显示可点开的链接卡片；播过的记在 `xh-campus-seen`。
- 聊天工具：`campus_news{category}`（最新几条）、`campus_search{keyword}`（在缓存里找，例如“最近有什么讲座”“穿梭巴士”）；要打开原文走现有 `open_url`（会先问你）。
- 面板「校园」页下半部分：学校 / 身份、播报开关、来源开关、RSS 管理（添加时先试抓一次并显示标题）、「现在刷新」、最近条目列表（点开原文）。

### E · 灵动性：主动搭话的话题挑选

把现在“随便说一句”的主动搭话改成**先挑话题再开口**，每类有冷却时间和每日上限：

| 话题 | 什么时候 | 冷却 |
|---|---|---|
| 事件回访 | 事件日期已过、还没问过 | 每事件一次 |
| DDL 关心 | 48 小时内有未完成 DDL、你在用电脑 | 4 小时 |
| 提起往事 | 记忆 / 小结里有和当前场景相关的内容 | 6 小时 |
| 校园新闻 | 当天还没播 | 每天一次 |
| 早安 + 运势 / 今日 DDL | 早上第一次用电脑 | 每天一次 |
| 场景 / 时间 / 天气闲聊 | 兜底 | — |

仍然受「主动搭话」频率、免打扰、会议 / 游戏 / 隐私 / 全屏安静、她正在忙等现有规则约束。

## 6. 风险

- 学校网站改版会让解析失效：失败时静默跳过该来源，面板显示“上次刷新失败”。
- 每日小结和概括新闻会多花一点 token（每天约 2–3 次小请求）。
- 主动提起往事分寸难拿：默认频率保守，面板可关「主动提起往事」。
