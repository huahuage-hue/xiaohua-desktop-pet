## 1. 分四期做，每期都能单独构建、冒烟、回滚

开工前：`git init`（忽略 `target/ .backups/ dist/ psd/raw/`），并把 v0.5.0 源码打一份 `.backups\src-v0.5.0-<时间>.zip`。

### 第 1 期 · 聊天界面（漫画对白 + 侧边聊天窗）

- **漫画对白（主窗口内）**：删掉现在占 67% 高度的对话卡；双击她 → 脚边出现一条约 34px 的细输入栏（奶油纸风格，含 🧠思考 / 👀看屏幕 / ⤢展开 三个小按钮）；她的回复走头顶 chat 气泡，长回复分页轮播；整个人始终可见。
- **侧边聊天窗（新 WebView 窗口 `label=chat`）**：无边框奶油纸窗，约 340×520，可拉高；贴在她左/右侧（按屏幕半边自动选），她被拖动 / 贴边时跟着走；显示完整历史（按天）、可折叠的「她想了想…」、工具调用卡片（“她帮你打开了 记事本 ✓”）、确认按钮。
- **数据流不重构**：对话逻辑仍在桌宠窗口（`chat.js`），侧边窗只是视图：
  - 桌宠 → 侧边窗：`pet://chatui {kind: user|start|mood|think|delta|tool|confirm|end, ...}`
  - 侧边窗 → 桌宠：沿用 `pet://cmd {type:'say'|'stop'|'retry'|'confirm', ...}`
  - 历史从共享的 `localStorage['xh-chat-log']` 读。
- 窗口创建同面板：**async 命令里建**，`additionalBrowserArgs` 三处完全一致。

### 第 2 期 · 深度思考 + 帮你做事（工具调用）

- **深度思考**：输入栏 🧠 开关（本次生效）；按服务商用思考模型（DeepSeek `deepseek-reasoner`、通义 `qwen-plus`+`enable_thinking`、智谱 `thinking:{type:enabled}`、自定义可填）。Rust 解析 `delta.reasoning_content` → `kind: think`；漫画模式下她做「思考」动作 + 气泡思考点，侧边窗可展开看过程。思考内容不进记忆、不存日志正文。
- **工具调用**：OpenAI 兼容 `tools` / 流式 `tool_calls`；Rust 累积分片后发 `kind: tool`；`chat.js` 执行后回填 `role: tool` 再请求，最多 4 步。

| 工具 | 说明 | 需要你点确认 |
|---|---|---|
| `get_time` / `get_weather` | 复用小助手天气 | 否 |
| `set_reminder(minutes, text)` | 到点她跳出来提醒，存 localStorage，重启不丢 | 否 |
| `take_note(text)` | 记到「小嬅的便签」，面板可看/删 | 否 |
| `open_url(url)` / `web_search(query)` | 只允许 http/https；搜索 = 在浏览器打开必应搜索页 | 是 |
| `open_app(name)` | 在开始菜单快捷方式里模糊匹配后打开 | 是 |
| `read_clipboard` / `write_clipboard(text)` | 读会把内容发给模型，所以也要确认 | 是 |
| `look_screen(question)` | 见第 3 期 | 由「看屏幕」设置决定 |

  - 确认卡：漫画模式在气泡下出现「好 / 不要」；侧边窗出现卡片。60 秒不点视为拒绝。
  - 思考模式与工具不在同一请求里混用（多数思考模型不支持 tools）。
  - 面板「对话」加总开关「让她帮我做事」，模型不支持 tools 时自动降级为纯聊天并提示。

### 第 3 期 · 看屏幕（按需 + 偶尔主动看）

- Rust `screen.rs`：GDI 截前台窗口所在显示器（不带 CAPTUREBLT，桌宠/聊天窗等分层窗口不入镜，需实测），缩到最长边 1280，JPEG 编码成 base64，**只在内存，不写盘**。
- 两段式：截图 → **视觉模型**（面板单独配置：智谱 `glm-4v-flash`(免费) / 通义 `qwen-vl-plus` / Kimi vision / Ollama `qwen2.5vl` / 自定义）生成 ≤150 字描述 → 作为工具结果交给聊天模型。聊天模型不用支持图片（DeepSeek 也能用）。
- 触发：你说“看看我屏幕/帮我看下这个报错”（模型调用 `look_screen`）、点 👀 按钮、或开启「主动看」后部分主动搭话会先看一眼。
- 隐私硬闸（Rust + 前端双重判断）：场景总开关关、前台是 `private` 类 / 黑名单 / 面板自身时一律不截；首次使用弹一次说明；每次看屏幕在聊天里留「👀 她看了一眼屏幕」记录。

### 第 4 期 · 自动更新（Gitee）

- `tauri-plugin-updater` + `tauri-plugin-process`；`createUpdaterArtifacts: true`；用 `cargo tauri signer generate` 生成签名密钥，**私钥放在源码目录外**（如 `%USERPROFILE%\.tauri\xiaohua.key`），丢了就无法再给旧版本推更新。
- 版本清单：`https://gitee.com/<你的用户名>/<仓库>/raw/master/latest.json`；安装包：发行版附件 `.../releases/download/v<版本>/小嬅桌宠_<版本>_x64-setup.exe`。可再挂一个备用地址。
- 行为：启动 1 分钟后 + 每天检查一次；有新版 → 她冒气泡“有新版本啦”，面板「设置」显示更新说明和「立即更新」；下载有进度，装完自动重启。设置项「自动检查更新」可关。
- `build.ps1` 加 `-Release`：读私钥签名 → 生成 `latest.json` → 列出要上传到 Gitee 的文件。首次上传你手动做（或之后给 Gitee 令牌再自动化）。
- 本地验证：环境变量 `XH_UPDATE_URL` 指向本机假服务器，构建 0.6.0 → 用假 0.6.1 测完整更新流程。
- 注意：便携版通过更新会变成安装版（NSIS 装到 `%LOCALAPPDATA%`）。

## 4. 每期验证

- 静态：`node --check`（含 panel/chatwin 内联脚本提取）、`cargo check`。
- 构建：`build.ps1 -SkipInstall`。
- 真机 CDP（先备份 `xh-pet / xh-chat-log / xh-memory-v2 / xh-onboarded`，测完还原）：
  - 1 期：漫画输入栏 / 侧边窗开合、跟随拖动与贴边、穿透不受影响、历史同步、Esc/停止/重发。
  - 2 期：本地假 LLM 返回 `reasoning_content` 和 `tool_calls`，验证思考展示、确认卡同意/拒绝/超时、提醒到点、4 步上限。
  - 3 期：前台为记事本时能截图且画面里没有桌宠；前台为微信/密码管理器时拒绝；假视觉服务验证请求体含图片、描述回填。
  - 4 期：本地假更新服务器跑通 0.6.0 → 0.6.1。
- 不调用真实付费接口；真实服务商只在你同意后做一次连通测试。
