# 小嬅桌宠 · v0.6.0（Tauri 2）

透明窗口、点击穿透、拖动、贴边、托盘。角色渲染直接复用网页预览的 `assets/`。

## 构建（Windows 10/11）

1. 在 `desktop-pet` 文件夹里右键 `build.ps1` →“使用 PowerShell 运行”。如果提示禁止运行脚本，改用命令：
   ```powershell
   powershell -ExecutionPolicy Bypass -File build.ps1
   ```
2. 第一次运行会自动安装 **VS C++ 生成工具**、**Rust** 和 **tauri-cli**，大约 3–5GB、20–30 分钟，期间要点一次管理员确认。以后再构建只要 1–2 分钟。
3. 构建完成后会自动复制到 `D:\小嬅桌宠\`（可用 `-OutDir 路径` 改），并打开该文件夹：
   - 免安装版：`小嬅桌宠.exe`，双击就能运行；
   - 安装包：`安装包\小嬅桌宠_0.6.0_x64-setup.exe`（只复制当前版本）；
   - `使用说明.txt`。
   如果桌宠正在运行，会先自动关闭再覆盖。`-NoOpen` 构建完不打开资源管理器。
4. **v0.6.0 起安装包必须签名**（自动更新靠它校验）：私钥默认在 `%USERPROFILE%\.tauri\xiaohua-updater.key`（不在源码目录里，务必另外备份；丢了就没法给已装的旧版推更新），公钥写在 `tauri.conf.json → plugins.updater.pubkey`。没有私钥时 `build.ps1` 会报错并提示生成命令。
5. 发布新版本：`build.ps1 -SkipInstall -Release -Notes "更新说明"`，在 `D:\小嬅桌宠\发布\v版本\` 生成英文名安装包、`latest.json` 和 `发布说明.txt`（GitHub Releases 上传步骤）；`-UpdateBase` 指定发行版下载地址前缀。

调试网页部分时，用 `build.ps1 -Dev` 启动开发模式，改完网页按 F5 刷新即可看到效果。

> 每次构建都会先把项目根目录 `assets/` 里的 9 个 js 和 `assets/wardrobe/` 图集复制到 `web/assets/`，所以网页预览里的改动会自动带进桌宠。

## 使用

| 操作 | 效果 |
|---|---|
| 点头 / 身体 / 云朵 | 和网页版一样：摸头、害羞或歪头、云朵开心；同一处连点 3 次她会生气 |
| 双击她 | 打开聊天：默认是脚边的漫画输入栏（她在头顶气泡里回话），也可在面板改成侧边聊天窗 |
| 按住角色拖动 | 拖着整个窗口走，她像被拎住的挂件一样以抓住的位置为支点摇摆（见下方“拖动摇摆”），松手后落地 |
| 拖到屏幕左右边缘（40px 以内） | 吸附过去，只露出 60%。鼠标移上去她会滑出来，移开 1.5 秒后缩回 |
| 点在角色以外的透明区域 | 直接点到下面的窗口（点击穿透） |
| **右键点角色** | 打开控制面板（在她旁边弹出，关掉只是隐藏） |
| 鼠标离开很久再靠近 | 她会打招呼或探头看你 |
| 鼠标停在她身上 2 秒 | 歪头看你 |
| 鼠标在她身上快速来回晃 | 她会生气（冷却 6 秒） |
| 托盘图标左键 | 显示 / 隐藏 |
| 托盘图标右键 | 控制面板…、显示 / 隐藏、置顶、开机自启、大小 75 / 100 / 125%、退出 |

### 开机自启（v0.2.1，`src-tauri/src/autostart.rs`）

- 写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的「小嬅桌宠」= `"exe路径" --autostart`；只影响当前用户，不需要管理员；默认关闭；
- 入口：控制面板「设置 → 窗口 → 开机自动启动」和托盘「开机自启」，状态每次实时读注册表，两处通过 `pet://autostart` 事件同步；
- 命令：`autostart_get` / `autostart_set { on }`（返回实际状态）/ `launched_autostart`；
- 启动时若已开启、登记的 exe 已经不存在（被挪过 / 删了），自动改成当前路径；v0.6.0 起登记的 exe 还在就不动，避免随手运行一份副本就把自启抢走；
- 带 `--autostart` 启动时，`pet.html` 的 `XH_GREET_GATE` 让 `app.js` 跳过开场 greet，开机不出声。

### 控制面板（v0.3.0：5 个标签页）

- **互动**：16 个动作按钮、睡觉 / 叫醒、问时间、问天气、和她聊天；
- **换装**：5 套衣服、6 个配饰槽（头发 / 脖子 / 肩上 / 挂坠 / 胸口 / 脸上）、跟随时间自动换装、恢复原版；
- **小助手**：整点报时 + 免打扰时段、摸头顺口说、深夜劝睡、天气播报 + 城市搜索、喝水休息提醒（30/45/60/90 分）；
- **对话**：开关、服务商、接口地址、模型、密钥（只显示末 4 位）、双击时的聊天方式、说话风格、回复长度、主动搭话、让她帮我做事、深度思考 + 思考模型、测试连接、桌面感知、看屏幕（视觉服务 / 模型 / 密钥 / 看一眼试试）、记忆分条管理、提醒与便签、聊天记录（按天分组 / 搜索 / 删除 / 导出导入）+ 发消息；
- **设置**：随机动作频率、鼠标互动、动作台词、视线跟随、声音、大小、置顶、云朵和星星、拖动摇摆、窗口操作、更新（自动检查 / 检查更新 / 立即更新）。

设置保存在本地，下次启动沿用。

### 气泡（v0.2.0，`assets/app-bubble.js`）

- 奶油纸 `#FBF6EA` + 暖棕描边 `#8B6A4E`，尾巴是 3 个由大到小的云团，指向头顶；报时 / 天气左上角有小星星；
- 4 种：`say` 胶囊、`time` 小时钟、`weather` 天气图标 + 温度、`chat` 多行 + 打字机 + “…”思考动画；
- 停留 2–8 秒（按字数），聊天多 3 秒；锚点用 `R.headScreen()` 跟随头部变形和拖动摇摆，气泡随摇摆轻转；
- 桌宠窗口 300×610：顶部 70px 是气泡区（透明、点击穿透），角色画布在下方 540px，大小与旧版一致；旧版窗口位置启动时自动上移补齐。

### 小助手（`assets/app-assist.js`）

- 每 15 秒检查一次；整点报时、天气（Open-Meteo，30 分钟缓存，8 秒超时，失败静默）、提醒、劝睡；
- 她在做动作 / 睡觉 / 聊天时，台词排队最多等 20 秒；
- 桌宠里窗口大多数时间点击穿透，由全局光标移动判断“有人在用电脑”。

### AI 对话（v0.5.0 记忆 v2；v0.6.0 聊天界面重做，`web/chat.js` / `memory.js` + `src-tauri/src/chat.rs`）

- 兼容 OpenAI `/chat/completions` 的流式接口；Rust 用 ureq + rustls 在后台线程读 SSE，每段文字以 `pet://chat` 事件推回网页（v0.6.0 起还有 `think` 思考过程、`tool` 工具调用）；
- 密钥由 Rust 存在 `%APPDATA%\com.xiaohua.desktoppet\chat.json`，网页只能拿到“已设置 + 末 4 位”；本机地址（Ollama）可不填密钥；
- **漫画对白**（v0.6.0 默认）：双击她，脚边出现一条输入栏（灯泡 = 深度思考、眼睛 = 给她看屏幕、对话框 = 展开聊天窗、×），她的回复走头顶 chat 气泡；输入栏开着时只拦截她身上和输入栏区域，其余照样点击穿透；点别处 / Esc 收起；
- **侧边聊天窗**（v0.6.0，`web/chatwin.html`，窗口 label=chat）：贴在她左 / 右侧（按屏幕半边、放不下自动换边），`main.rs` 轮询里 `dock_chat` 让它跟着拖动 / 贴边走；完整记录按天分组、思考过程折叠块、她做的事（✓ / ✕ 标签）、做事前的确认卡、停止 / 重发；它只是视图——桌宠窗口用 `pet://chatui` 推进度，它用 `pet://cmd` 回话；
- 面板「对话 → 双击她时」选默认打开哪种（`chatMode`：`comic` / `side`，`sv = 7`）；
- 系统提示词要求回复以 `[开心]` `[害羞]` `[生气]` `[困]` `[思考]` 等标签开头 → `XH.pet.emote()` 播动作；
- 记忆 v2（`localStorage['xh-memory-v2']`）：`profile`（称呼 / 生日 / 城市 / 工作 / 喜欢 / 不喜欢 / 忌口）+ `facts` / `events` / `promises`；每 3 轮用一次独立请求抽取严格 JSON，去重合并、上限 50/30/20，事件 90 天过期；旧版一段式摘要首次读取时自动迁移；
- 注入提示词：档案全量 + 与当前话题相关的 top 8 事实 + 近 3 条事件 + 未完成约定；面板可编辑 / 删除 / 置顶 / 导出；
- 本机识别「忘掉 咖啡」「不要记得 …」「把关于…的记忆删掉」，直接删条目并回一句，不发给模型；
- 上下文保留最近 10 轮（`localStorage['xh-chat-log']`）；出错时撤回刚才那句并用台词说明（401/402/404/429/5xx/断网/30 秒无动静超时）。

### 深度思考 + 帮你做事（v0.6.0，`web/tools.js` + `src-tauri/src/agent.rs`）

- 深度思考（`think`，输入栏灯泡 / 面板开关）：换思考模型或打开思考参数（DeepSeek `deepseek-reasoner`、通义 `enable_thinking`、智谱 `glm-4.5-flash` + `thinking`、Kimi `kimi-k2-thinking`；`thinkModel` 可覆盖）；`reasoning_content` / `reasoning` / 正文开头的 `<think>` 都会转成思考过程，不进记录；思考模式不带工具；
- 帮你做事（`agentOn`，默认开）：OpenAI `tools` 格式，流式 `tool_calls` 分片在 Rust 拼好；本地执行后回填 `role: tool` 再请求，最多 4 步；模型不认 tools / 思考参数时（400/422）自动去掉重来；
- 工具：看时间、查天气、设 / 看 / 取消提醒（`xh-reminders`，到点走对话气泡并写进记录）、记 / 看便签（`xh-notes`）、打开网页（只认 http/https）、浏览器必应搜索、打开开始菜单里的程序（别名表 + 快捷方式模糊匹配，跳过卸载类，Rust 再校验只能开开始菜单目录里的 .lnk/.url）、读 / 写剪贴板、看屏幕；
- 会动电脑或把内容发出去的动作先在输入栏 / 聊天窗问「好 / 不要」，60 秒不答算不要；面板「提醒与便签」可查看、删除。

### 看屏幕（v0.6.0，`src-tauri/src/screen.rs` + `web/vision.js`，默认关）

- 两段式：`screen_capture` 截你正在用的窗口所在的显示器（前台是小嬅自己的窗口就沿 Z 序往下找）→ 最长边 1280 的 JPEG（约 150KB）只在内存 → 视觉模型（默认智谱 `glm-4v-flash`，也可选通义 / Kimi / Ollama / 自定义）描述成 150 字以内 → 交给聊天模型；聊天模型本身不用支持图片；
- 触发：你让她看（`look_screen` 工具，只在 `visionOn` 时提供）、点眼睛按钮（先看再答，本轮不再给 look_screen）、开了 `visionAuto` 时主动搭话前偶尔看一眼（30 分钟最多一次，记录里标「看了一眼屏幕」）；
- 隐私：首次使用先征求同意（`xh-vision-ok`）；隐私类进程 / 标题 / 黑名单网页端和 Rust 各拦一次；不碰任何窗口属性，小嬅自己的窗口可能进画面，由提示词让模型忽略。

### 自动更新（v0.6.0，`src-tauri/src/update.rs`）

- `tauri-plugin-updater`：`update_check` 读 `UPDATE_URLS`（GitHub raw `master/latest.json`，jsDelivr 兜底）；`update_install` 下载、校验 minisign 签名（含签名里的版本号）、passive 模式跑 NSIS 安装包，装完自动重开；下载超时 10 分钟（检查 30 秒）；
- 桌宠启动 1 分钟后 + 每天查一次（`autoUpdate`，默认开），每个新版本只提醒一次（`xh-update-seen`）；面板「设置 → 更新」显示说明和进度；
- 本机测试：环境变量 `XH_UPDATE_URL` 指向本机地址（只有 127.0.0.1 / localhost 允许 http），`update_install { dry: true }` 只下载校验不安装；
- 便携版通过更新会变成安装版（装到 `%LOCALAPPDATA%\小嬅桌宠`）。

### 桌面场景感知（v0.5.0，方案 B，`src-tauri/src/scene.rs` + `web/scene.js`）

- Rust 每 2 秒读前台窗口的进程名、标题和窗口矩形，判断是否全屏，通过 `pet://scene` 广播；只在本机，不截图、不读内容、不写盘（截图是单独的「看屏幕」，见下）；
- 归类：写代码 / 看视频 / 玩游戏 / 开会 / 处理文档 / 浏览网页 / 隐私应用；会议、游戏、密码 / 银行 / 聊天类应用和全屏时**不主动搭话**；
- 提示词只加一句“用户现在似乎在写代码”这类类别；「把窗口标题也告诉她」默认关闭，关闭时标题不会进入模型请求；
- 面板「对话 → 桌面感知」：总开关（默认开）、标题开关（默认关）、全屏安静（默认开）、全屏自动隐藏（默认关）、进程黑名单；
- 全屏自动隐藏通过 `pet_show` 明确显示 / 隐藏，退出全屏后自动回来；`sceneBlock` 支持逗号分隔的进程名片段。

### 拖动摇摆（v0.1.5）

- 支点 = 按下的位置（限制在身体范围内）。窗口位移先平滑成速度 / 加速度（τ 60 / 40ms），再驱动阻尼摆（ω≈11、ζ≈0.19，固定 1/240s 步长）：加速时脚往反方向荡、匀速时略后倾、急停 / 松手后荡过头再来回 2–3 下停住；
- 幅度：轻 ±10° / 正常 ±20°（实测往返拖约 ±10–14°）/ 夸张 ±28°，接近上限时软限幅；系统开了“减弱动态效果”时幅度减半；
- 往上提 → 身体拉长、下摆下坠；往下放 → 压扁、裙摆上飘；
- 分层滞后：身体 → 辫子 / 兜帽 / 呆毛 → 辫梢 / 下摆，各自按支点甩；双腿是更慢的二级摆，被拎着时脚轻轻荡、手臂下垂；
- 摆得太猛：眯眼、冒汗、皱眉；1.2 秒内高速来回甩 3 次以上 → 松手后转圈眼、摇头、气泡“晕乎乎…”；
- 落地动作力度按松手前速度缩放（0.6–1.6 倍）；
- 整体摇摆在顶点着色器里做（`uSwM`），眼部裁剪仍用摇摆前坐标；特效层（汗滴、音符等）用同一矩阵；点击坐标会反算回去，还在晃时点她也准；
- `main.rs` 每 30ms 推送 `[dx, dy]`（含 0），左键连续 3 次检测为松开才算松手（系统拖动循环里偶尔误读一次）；`start_drag` 在左键已松开时拒绝，避免松手后补发的旧事件再触发一次拖动。

### 自动动作

- 每 6–9 秒一个小动作（眨眼、呼吸加深、瞟一眼、轻歪头）；
- 每 20–25 秒一个正式动作，从点头、张望、歪头、小跳、挥手、拍云朵、哈欠、哼歌（飘音符）、发呆、探头里随机挑，不会连续重复；
- 深夜 23–6 点更容易打哈欠、发呆；
- 频率“低 / 高”会把以上间隔拉长 1.8 倍 / 缩短到 0.55 倍。

- 视线会跟着鼠标走，鼠标在窗口外面时也一样。
- 10 分钟没有操作她会睡着，点一下就醒。
- 窗口位置和大小会自动记住。如果上次所在的显示器被拔掉了，会回到主屏右下角。

### 音效

`assets/app-sfx.js` 用 Web Audio 实时合成，不带音频文件。每个动作一个短音（哼歌是跟着音符飘出的 5 个音）。
- 两层声音：叮叮 / 啵嗒这类**音色层**，加一层合成的**小女孩声色**（基频 420–700Hz + 共振峰模拟元音）。打招呼「哎~」、歪头「嗯？」、害羞「唔…」、生气「哼哼」、哈欠「啊~呼」、叫醒「嗯…？」、被拎起「呀」、哼歌「嗯~啦」。关掉人声只留音色层；
- v0.1.4 人声调整（更甜、更高、不尖）：音高整体 +3.5 个半音（约 520–780Hz）；声源由纯锯齿改为三角波 + 30% 锯齿；共振峰 F3 几乎去掉、元音偏圆；人声单独 3kHz −6dB 削峰 + 4.2kHz 低通；气声先过 2.2kHz 低通去嘶嘶声；颤音幅度降到 1/3，只给 0.3 秒以上的长音，且 0.15 秒后才进；
- 拖动：拎起来一声轻快的「咻」，落地是亮一点的「啵嗒」（原来 90–180Hz 的闷「咚」已去掉）；
- 总线带 5.5kHz 低通和轻压限，防刺耳、防叠音爆音；
- 旧设置里音量还是默认 40% 的，升级后自动改成 25%（由设置版本号 `sv` 控制，只迁移一次）；
- 待机小动作、收尾动作不出声；她自己随机做的正式动作音量减半；
- 深夜 23–6 点音量再减半；睡着后安静；同一音效 0.4 秒内不重复；
- 桌宠窗口以 `--autoplay-policy=no-user-gesture-required` 启动，所以不点她也能出声。这个参数在 `tauri.conf.json`（主窗口）和 `main.rs`（面板窗口）里各写了一份，**两处必须完全一致**，否则两个窗口无法共用 WebView2，面板会打不开。

## 工作原理

```
Rust（src-tauri/src/main.rs）                         网页（web/pet.js）
 每 30ms 读全局光标 ── pet://cursor ───────────────▶  看向光标；每 50ms 读光标处 ±6px 的画面透明度
                     ◀── set_passthrough(true/false) ─ 透明度 > 0.5：不穿透（能点）；< 0.35：穿透
 start_drag ◀───────────────────────────────────────  按下后移动超过 6px
 系统拖动窗口；左键松开（GetAsyncKeyState）
   → 贴边吸附 ── pet://drag-end ───────────────────▶  播放落地动作 drop
```

- 窗口处于点击穿透状态时，网页收不到任何鼠标事件，所以光标位置要由 Rust 推送给网页。
- 透明度读取用 `gl.readPixels`，每次只读 13×13 像素，紧跟在当帧渲染之后。

## 浏览器调试

直接用 Chrome 或 Edge 打开 `web/pet.html`（或者加上 `?debug`）：
- 棋盘格背景表示透明区域；
- 光标处的圆点：绿色 = 能点，红色 = 穿透，蓝色 = 拖动中；
- 左下角显示当前透明度。

浏览器里按住拖动也会摇摆、落地（窗口本身不动）；网页预览 `index.html` 同样可以拎着她晃。

## 已知限制

- 只适配了 Windows。macOS 的透明窗口要开 `macOSPrivateApi`，松手判定也需要另写，放到后续再做。
- 拖动时窗口由系统移动，摇摆根据窗口位移来算（约每 30ms 一次，网页端平滑后插值）。
- 显卡渲染中断时会先暂停画面，恢复后再继续，期间整个窗口都是穿透状态。
- 已在 Windows 本机实际编译运行（Rust 1.99 + MSVC 14.44 + WebView2）。只打 NSIS 安装包；MSI 需要下载 WiX，国内网络容易卡住，已关闭。
- `.cargo/config.toml` 配置了 rsproxy 镜像；在海外网络可删掉该文件。
- 面板窗口和侧边聊天窗都由 async 命令创建：Windows 上在同步命令里新建 WebView 会死锁（表现为面板白屏），改代码时注意保持 async；三个窗口的 `additionalBrowserArgs` 都用 `main.rs` 的 `BROWSER_ARGS`，并与 `tauri.conf.json` 主窗口保持一致。
- 真实服务商的思考 / 工具 / 图片消息格式只按 OpenAI 兼容格式实现，本机用假服务验证过；GitHub 发布链路要发第一个真实版本时实测。
