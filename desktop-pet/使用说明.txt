小嬅桌宠 v0.6.0 使用说明
========================

【启动】
  双击「小嬅桌宠.exe」。不用安装，整个文件夹可以随意移动或复制给别人。
  如果想装进开始菜单，运行「安装包」文件夹里的 setup.exe。
  需要 Windows 10/11（系统自带 WebView2；缺少时安装包会自动下载）。

【开机自动启动】（v0.2.1，默认关闭）
  控制面板 →「设置」→ 窗口 →「开机自动启动」，或右键托盘图标 → 勾选「开机自启」，两处同步。
  打开后，登录 Windows 时她会自动出现在上次的位置，开机时不会出声打招呼。
  只对当前用户生效，不需要管理员权限；在任务管理器「启动」页里也能看到和关闭「小嬅桌宠」。
  开着自启时把 exe 挪了位置也没关系：原来的文件不在了，下次手动打开她，会自动改成新路径。
  （原来的文件还在时不会改，免得随手运行一份副本就把开机自启抢过去。）
  不用了就先关掉这个开关再删文件夹，免得开机时找不到文件。

【和她互动】
  左键点头 / 身体 / 云朵   摸头、害羞或歪头、看云朵；同一处连点 3 次她会生气
  双击她                   和她聊天（需要先在控制面板「对话」里开启，见下）
  按住拖动                 把她搬到任何地方，松手会落地；拖到屏幕左右边缘会藏起一半，鼠标靠近时探出来
                           拎着时她会像挂件一样晃，来回甩太猛她会头晕
  右键点她                 打开「控制面板」
  点她以外的透明区域       直接点到下面的窗口（不挡操作；她头顶的气泡也不挡）

【v0.2.0 新气泡】
  奶油色小纸条 + 三个小云团尾巴，跟着她的头走，拖着晃时也跟着晃。
  报时会带小时钟、天气会带天气图标和温度、聊天时先冒“…”再一个字一个字打出来，她的嘴也会跟着动。

【小助手】（控制面板 →「小助手」，每项都能单独开关）
  整点报时       默认开。早、中、晚、深夜台词不一样；免打扰时段默认 23:00–7:00
  摸头时顺口说   默认开。摸她的头，偶尔告诉你时间或天气
  深夜劝睡       默认开。零点到五点还在用电脑，每晚提醒一次
  天气播报       默认关。先搜索并选一个城市（中文即可）；每天第一次启动说一次，之后每 3 小时一次，
                 等会儿要下雨、明天降温、很热很冷时会特别提醒。数据来自 Open-Meteo（免费、不用注册）。
                 断网时不说话，也不会报错。
  喝水休息提醒   默认关。间隔 30 / 45 / 60 / 90 分钟；只在你用电脑时计时，离开 5 分钟会重新算
  控制面板「互动」里也有「现在几点？」「今天天气？」按钮。

【和她聊天（AI 对话，可选）】
  需要你自己的大模型 API 密钥（DeepSeek 便宜好用，注册后在 platform.deepseek.com 创建）。
  1. 控制面板 →「对话」→ 打开「开启对话」
  2. 服务商选 DeepSeek（也支持 通义千问 / Kimi / 智谱 / 本地 Ollama / 自定义兼容 OpenAI 的接口）
  3. 粘贴密钥 → 点「保存」→ 点「测试连接」，看到“连上了”就好
  4. 双击小嬅（或右键托盘 →「和她聊天」），她脚边会出现一条输入栏（漫画对白）：
     打字后按 Enter，她在头顶的气泡里一个字一个字回你，整个人一直看得见；
     想打断就点「■」，出错可以点「重发」；点别处或按 Esc 收起。
     输入栏右边的小对话框按钮会打开「聊天窗」：贴在她旁边、跟着她走，能看全部聊天记录、
     她想了什么、帮你做了什么；聊天窗右上角可以收回到脚边。
     想双击直接打开聊天窗：控制面板「对话 → 双击她时」选「聊天窗」。
  她会根据心情做动作（开心、害羞、生气、犯困、思考…）。
  记忆会分条整理：档案（称呼 / 生日 / 城市 / 工作 / 喜好 / 忌口）、事实、事件、约定。
  面板「对话 → 记忆」里能改、能删、能置顶，也能导出 / 导入；说「忘掉 咖啡」她就删掉对应那条。
  旧的记忆摘要会自动迁移，不用手动处理。
  说话风格：小嬅本色 / 简洁助手；回复长度：短（约 40 字）/ 中（约 100 字）。
  密钥只保存在本机（%APPDATA%\com.xiaohua.desktoppet\chat.json），面板里只显示末 4 位。
  聊天内容会发给你选的服务商；不想用就保持「开启对话」关闭，什么都不会发出去。
  出错时她会直接告诉你：密钥不对 / 余额不够 / 网络断了 / 等太久没回音（30 秒）等。

【深度思考和帮你做事】（v0.6.0）
  深度思考：点输入栏 / 聊天窗的灯泡（或面板「对话 → 深度思考」），她会换成思考模型、想得更久更认真，
           聊天窗里能点开看她想了什么。回复会慢一些，也更费额度；再点一下灯泡关掉。
  帮你做事（面板「对话 → 让她帮我做事」，默认开）：直接跟她说就行，例如
    「十分钟后提醒我喝水」「八点提醒我开会」「帮我记一下：周五交报告」「看看我有哪些提醒」
    「帮我打开记事本 / 网易云」「帮我搜一下明天的天气」「把这段话复制到剪贴板」「看看我复制了什么」
  打开网页、打开程序、搜索、读写剪贴板之前，她都会先问你「好 / 不要」，60 秒不点就算不要。
  她不会删文件、不会运行命令。提醒和便签在面板「对话 → 提醒与便签」里查看和删除。

【看屏幕】（v0.6.0，面板「对话 → 看屏幕」，默认关）
  打开后，你说「看看我的屏幕」「帮我看下这个报错」，或点输入栏 / 聊天窗的眼睛按钮，她会截一张图，
  交给你选的视觉模型看一眼再回答你。截图只在内存里，看完就丢，不保存。
  1. 打开「让她能看屏幕」
  2. 视觉服务推荐「智谱 glm-4v-flash（免费）」：在 open.bigmodel.cn 注册 → API Keys 创建密钥 → 粘贴 →「保存」
     （和聊天是同一家就不用再填）；也可以选通义 / Kimi / 本地 Ollama / 自定义
  3. 点「看一眼试试」，第一次会问你同不同意
  微信、QQ、密码管理器、网银 / 支付 / 无痕窗口和黑名单里的程序永远不截。
  「偶尔主动看一眼」：主动搭话前偶尔先看看你在做什么（最多 30 分钟一次），聊天记录里会标出来。

【桌面感知】（控制面板 →「对话」→「桌面感知」，默认开）
  她会模糊知道你正在用哪类软件：写代码 / 看视频 / 玩游戏 / 开会 / 处理文档 / 浏览网页。
  只在本机读前台窗口的进程名和标题，用来判断类别；不截图、不读内容、不写盘（截图是单独的「看屏幕」）。
  「把窗口标题也告诉她」默认关闭：关闭时只把类别写进提示词，标题不会发给模型。
  会议、游戏、密码 / 银行 / 聊天类应用和全屏时会自动安静，不主动搭话。
  也可以打开「全屏时自动躲起来」，退出全屏后她会自己回来；还能填进程黑名单。

【她自己会做的事】
  每隔几秒：眨眼、东张西望、歪头、晃身体、深呼吸
  每隔 20–25 秒：点头、张望、小跳、挥手、看云朵、哼歌、发呆、偷看你、打哈欠（深夜更爱打哈欠）
  闲下来：侧着身子在桌面上慢慢走，走到屏幕边上会坐下晃腿（设置里可关；拖动、聊天、睡着时不会走）
  鼠标从远处靠近：打招呼或偷看你
  鼠标停在她身上 2 秒：歪头
  鼠标在她身上来回乱晃：生气
  10 分钟没人理她：睡着（点一下就醒；和她说话也会醒）

【声音】
  每个动作配了轻柔的小音效（实时合成，不需要联网，也没有音频文件），还带一点小女孩的声音。
  控制面板 →「设置」→ 声音：音效开关、音量（默认 25%）、小女孩声音开关、试听。
  她自己随机做动作时音量减半；深夜 23–6 点再减半；眨眼等小动作和睡着时不出声。

【控制面板】（右键她，或右键托盘图标 →「控制面板…」）
  互动：16 个动作按钮、睡觉 / 叫醒、问时间、问天气、和她聊天
  换装：5 套日常 + 6 套节日衣服、7 个配饰槽、跟随时间 / 节日自动换装、恢复原版
  小助手：报时、免打扰、摸头顺口说、深夜劝睡、天气 + 城市、喝水休息提醒
  对话：开关、服务商、接口地址、模型、密钥、双击她时、说话风格、回复长度、主动搭话、让她帮我做事、深度思考、
        测试连接、桌面感知、看屏幕、记忆分条管理（改 / 删 / 置顶 / 导出导入）、提醒与便签、
        聊天记录（按天分组、搜索、删单条、导出导入，也能在这里发消息）
  设置：随机动作频率、鼠标互动、动作台词、视线跟随、声音、大小、置顶、云朵和星星、拖动摇摆、移回右下角、隐藏、退出、
        更新（自动检查更新、检查更新、立即更新）
  所有设置会自动保存。

【换装】（控制面板 →「换装」）
  5 套：原版桦叶 / 晨露奶油 / 焦糖格纹 / 月白星纹 / 星夜斗篷。
  6 个配饰槽：头发、脖子、肩上、挂坠、胸口、脸上；点一下穿上，再点一下脱下。
  「跟随时间自动换装」默认开：06–11 晨露、11–17 原版、17–21 格纹（周五六星夜）、21–06 月白。
  手动选衣服会关掉自动；点「恢复原版」清空配饰并回到原版。
  v0.4.0 节日装：春节（除夕到元宵）、情人节 / 七夕、端午、中秋、万圣（10/25–11/1）、圣诞（12/18–12/26）。
    到了节日那几天会自动换上节日装和配饰；「节日自动换装」开关可关掉（需先开着跟随时间）。
    新增「头顶」槽：玉兔耳朵 / 小巫师帽 / 冬青鹿角，和大蝴蝶结二选一。
  v0.4.1：修复控制面板打开后点不动的问题；点节日套装会自动带上该节日的标志性配饰。
  v0.4.2：修复玉兔耳朵右耳缺一块的问题。
  v0.4.3：修复兜帽和白缎带上露出背景的小洞。
   v0.4.4：修复呆毛根部摆动时兜帽露底的小缝；桦枝叶子跟着兜帽一起摆。
   v0.3.2：围巾直接盖在领口上，不再用额外的肤色补丁；中间小洞露出原画领口。
   v0.5.0：聊天输入条升级为对话卡（可拖标题栏挪动）；记忆改成档案 + 事实 / 事件 / 约定，可分条管理；
           新增桌面感知（默认只给软件类别，会议 / 游戏 / 隐私 / 全屏时安静，可全屏自动隐藏）。
   v0.6.0：聊天改成漫画对白（她始终看得见）+ 跟着她走的聊天窗；深度思考；让她帮你做事；看屏幕；自动更新。

【托盘图标】（屏幕右下角，小嬅头像）
  左键：显示 / 隐藏小嬅
  右键：和她聊天、控制面板、显示/隐藏、置顶、开机自启、大小、退出

【自动更新】（v0.6.0，面板「设置 → 更新」）
  默认每天自动检查一次。有新版本时她会告诉你一声，到「设置 → 更新」里看更新说明、点「立即更新」：
  下载完会核对安装包签名，对不上就不装；安装时她会离开一下，装好自己回来，设置和聊天记录都保留。
  免安装版点了更新会变成安装版（装到 %LOCALAPPDATA%\小嬅桌宠）。不想自动检查可以关掉开关。

【从旧版升级】
  直接替换 exe 即可，设置都会保留。窗口顶部多了一块透明的气泡区，她在屏幕上的位置不变。

【退出】
  控制面板「设置」里的「退出小嬅」，或者右键托盘图标 →「退出」。

【卸载】
  免安装版：先在控制面板关掉「开机自动启动」（如果开过），再删除这个文件夹。
  安装版：在「设置 → 应用」里卸载「小嬅桌宠」。
  设置、窗口位置和密钥保存在 %LOCALAPPDATA%\com.xiaohua.desktoppet 和 %APPDATA%\com.xiaohua.desktoppet，删掉这两个文件夹就能完全清除。
